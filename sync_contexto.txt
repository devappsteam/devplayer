# PROMPT TÉCNICO — MIGRAÇÃO M3U → XTREAM JSON (LARAVEL HIGH PERFORMANCE)

Você é um arquiteto backend especialista em Laravel, sistemas distribuídos e alta performance.
Preciso que você gere uma implementação profissional para migrar minha API IPTV de parsing M3U para consumo via Xtream Codes API (JSON).

====================================================
📌 CONTEXTO
====================================================

Atualmente:
- Minha API Laravel consome playlists M3U
- Faço parsing manual do arquivo
- Tenho problemas de performance e memória
- A base possui +500.000 registros

Objetivo:
- Eliminar completamente M3U
- Usar apenas padrão Xtream JSON (player_api.php)
- Construir arquitetura escalável e otimizada

====================================================

3) Usar:

4) Implementar:

====================================================
📌 ARQUITETURA ESPERADA
====================================================

Criar:

app/Services/XtreamService.php
app/Jobs/ImportStreamsJob.php
app/Http/Controllers/StreamController.php

Separação clara de responsabilidades:

XtreamService:
- Consome API externa
- Timeout 10s
- Retry 3x
- User-Agent customizado

ImportStreamsJob:
- Processa streams em chunks
- Insere via upsert()
- Evita duplicação

StreamController:
- Expõe endpoints internos paginados
