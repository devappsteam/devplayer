PROMPT ARQUITETURAL – IPTV WEB PLAYER (NÍVEL SÊNIOR)

Você é um Arquiteto de Software Sênior especializado em Streaming, MediaSource Extensions, HLS, Video Delivery e sistemas de alta disponibilidade.

Seu objetivo é projetar uma aplicação IPTV Web baseada em:

- Frontend: Vue 3 + Vite + TypeScript
- Backend: Laravel (API REST modular baseada em módulos)
- Player Engine customizado (baseado em HLS.js / MSE)
- Integração com Xtream Codes e M3U
- Sistema de buffer adaptativo
- Seleção automática de qualidade (ABR)
- Favoritos sincronizados
- Cache inteligente
- Alta resiliência a falhas de conexão

Não gere código inicialmente. Estruture arquitetura, módulos, responsabilidades e fluxos.

-----------------------------------------------------

1. OBJETIVO DO SISTEMA

Criar um player IPTV Web desktop com:

- Reprodução fluida
- Troca rápida de canais (zapping rápido)
- Buffer inteligente
- Seleção automática de qualidade
- Fallback automático de stream
- Cache de playlists
- Persistência de favoritos
- Monitoramento de conexão em tempo real

O sistema deve se comportar como um aplicativo nativo rodando no navegador.

- LOADING

- PLAYING

- SWITCHING_QUALITY
- SWITCHING_CHANNEL

Submódulos Internos

- Validar disponibilidade
- Gerenciar múltiplas qualidades

Quality Engine (ABR)
- Medir largura de banda real
- Calcular bitrate ideal
- Monitorar buffer
- Antecipar queda de conexão
- Evitar oscillation de qualidade

Buffer Controller
- Ajustar maxBufferLength
- Ajustar maxMaxBufferLength
- Preload de segmentos
- Buffer diferenciado para Live vs VOD

-----------------------------------------------------

5. ESTRATÉGIA DE ADAPTIVE BITRATE (ABR)

Definir algoritmo baseado em:

- Throughput médio ponderado (EWMA)
- Buffer occupancy
- Margem de segurança percentual
- Threshold de downgrade preventivo

Estratégia:

- Iniciar em qualidade média
- Subir gradualmente
- Descer rapidamente
- Evitar troca constante

-----------------------------------------------------

6. TROCA RÁPIDA DE CANAL (FAST ZAP)

Implementar:

- Preload do próximo canal
- Cancelamento inteligente de requisições
- Reuso de instância do player
- Limpeza controlada de buffer

Objetivo:
Troca inferior a 1 segundo em redes estáveis
